PINNA EDITIONS

Self-InitiatedPublishing2024

Overview

A self-initiated publishing imprint for visual research, printed experiments and small editions.

PINNA EDITIONS is a compact publishing framework that treats each release as part of a numbered system. A fixed spine, changing colour field and strict information hierarchy make the series coherent while leaving space for radically different content.
